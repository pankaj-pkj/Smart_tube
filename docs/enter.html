Reconnect

Google Console mein ye Authorized redirect URI exactly daalna hai:

https://smarttube.example.com/auth/youtube/callback
  1. console.cloud.google.com par project banao (free).
  2. YouTube Data API v3 enable karo.
  3. OAuth consent screen: type External, apni Gmail ko Test user mein add karo.
  4. Credentials → Create → OAuth client ID → Web application → upar wala redirect URI paste karo.
  5. Client ID + secret upar bharo, Connect YouTube dabao, Google par allow kar do.

📸 Instagram connected

Reels publish + auto comment. Graph API long-lived token chahiye.

@my.reels.page
8420 followers · 96 posts
Instagram apni API se posting sirf Business/Creator account par deta hai jo ek Facebook Page se linked ho — personal account par Meta khud allow nahi karta. Switch karna free hai: Instagram app → Settings → Account type → Switch to Creator.
  1. Instagram account ko Creator/Business banao aur ek Facebook Page se link karo.
  2. developers.facebook.com par app banao → Instagram Graph API add karo.
  3. Graph API Explorer se permissions lo: instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement.
  4. Short token ko 60-din wale long-lived token mein exchange karo.
  5. /me/accounts → Page ID → ?fields=instagram_business_account se IG user ID milega.
